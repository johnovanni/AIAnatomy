This lesson will show a recurrent network, which carries a memory vector from one character to the next, trained on the same fables as the transformer. You will compare the two for loss, training speed and how far back each remembers, and see the recurrent network's memory after each character. It will explain why attention replaced recurrence, without overstating it, since recurrent networks are still used in places. This is standard textbook material.
