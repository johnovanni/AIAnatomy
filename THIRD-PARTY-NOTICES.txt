  Name:        Optical Recognition of Handwritten Digits (UCI Machine Learning Repository, dataset 80)

  Source:      https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits

               The UCI page says: "This allows for the sharing and adaptation of the datasets for any purpose, provided that
               the appropriate credit is given."
  Citation:    Alpaydin, E. & Kaynak, C. (1998). Optical Recognition of Handwritten Digits [Dataset]. UCI Machine Learning
               Repository. https://doi.org/10.24432/C50P49
  Subset:      UCI's own split. From optdigits.tra (training) the first 376 images of each digit in file order (3,760 images);
               from optdigits.tes (test) the first 174 of each digit (1,740 images). 376 and 174 are the smallest per-digit
               counts in those files, so each set has the same number of every digit. The rest are not used.
  Conversion:  Each 8x8 image keeps its values (0 to 16) scaled to 0 to 255 as round(v x 255 / 16), and is stored in this
               project's own gzip-compressed AIDIGITS format (tools/AIAnatomy.Pretrain, subcommand digits-subset).
               This is an adaptation of the original data.
